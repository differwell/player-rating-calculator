# 🏆 Калькулятор уровня игроков

Интерактивный веб-калькулятор для оценки игроков по 6 критериям с весами.

## Возможности

- Добавление / редактирование игроков
- Оценка от нескольких оценщиков (настраиваемое количество)
- Расчёт среднего балла (с весами и без)
- Определение уровня (Тир) по настраиваемой шкале
- Сравнение игроков на радарной диаграмме
- Экспорт в CSV
- Сохранение данных в JSON (не теряются при перезапуске)
- Тёмная тема
